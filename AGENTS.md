# Repo: QR CRM SAAS

Restaurant management platform: digital menus, QR ordering, delivery, reservations, reviews, staff management, subscriptions.

## Stack

- **Backend**: Convex (`convex/`) with `@convex-dev/auth@0.0.92` (email/password only)
- **Frontend**: React 19 + Vite 8 + React Router v7 + i18next + lucide-react + recharts
- **Auth**: `convex/auth.ts` uses `Password` provider only. `auth.config.ts` domain MUST be `process.env.CONVEX_SITE_URL` (not `SITE_URL`) — the Convex OIDC discovery endpoint lives there.
- **Styling**: Custom CSS (no Tailwind). Design tokens in `src/index.css` (`--gold: #E2B36B`, `--bg-*`, `--glass-*`). Dark mode forced via `data-theme="dark"`. Per-component CSS files co-located with pages.
- **Payments**: Lemon Squeezy. Checkout links in `src/pages/Tarifs.tsx`, variant→plan map in `convex/subscriptionConfig.ts`, webhook handler in `convex/http.ts` (HMAC-SHA256 signature validation, no ngrok needed).
- **Build**: `npm run dev` = `vite`, `npm run build` = `tsc -b && vite build`, `npm run lint` = `eslint .`
- **TypeScript**: strict (`noUnusedLocals`, `noUnusedParameters`, `verbatimModuleSyntax`, `erasableSyntaxOnly`)
- **Deploy**: `npx convex dev` → auto-syncs to dev (`hidden-herring-940`). `npx convex deploy` → pushes to prod (`fortunate-mole-320`). Vercel auto-deploys from GitHub main (`vercel.json` SPA rewrites).

## Project structure

```
convex/               # Backend (file-based routing)
  schema.ts           # 10 tables + authTables: profiles, menu, orders, staff, drivers, driverLocations, reservations, reviews, subscriptions
  auth.ts             # convexAuth({ providers: [Password] })
  auth.config.ts      # domain: process.env.CONVEX_SITE_URL
  http.ts             # Lemon Squeezy webhook + auth routes
  users.ts            # me (identity+subscription), getSubject, linkSubscription
  subscriptionConfig.ts # variantId → plan mapping
  _generated/         # Auto-generated, never edit
src/
  main.tsx            # ConvexAuthProvider with custom authStorage (localStorage vs sessionStorage via __convex_auth_remember flag)
  App.tsx             # React Router routes, ProtectedRoute (checks ?demo=ultimate bypass)
  pages/              # One .tsx + one .css per page
  components/         # ErrorBoundary.tsx
  index.css           # Design tokens, utility classes, glass-panel
```

## Key patterns & gotchas

- **Auth context**: `useConvexAuth()` gives `{ isAuthenticated, isLoading }`. `useQuery(api.users.me)` gives `{ subject, email, name, subscription }` or `null` if not authed. `getUserIdentity()` returns `null` when JWT is invalid (e.g., stale token after key rotation).
- **`?demo=ultimate`** on any protected route bypasses auth checks. Useful for UI testing.
- **`me` query** derives stable userId from `identity.subject.split('|')[0]` (userId without session suffix). Falls back to full subject, then email match, then old email-derived format.
- **Custom auth storage** in `main.tsx`: checks `__convex_auth_remember` in localStorage. If set, uses localStorage (persists). If unset, uses sessionStorage (lost on browser close).
- **Cross-page redirects** use `window.location.href` instead of `navigate()` (avoids React Router v7 synthetic event issues).
- **Convex queries**: `undefined` while loading, actual value when resolved. `null` when handler returns null. Distinguish carefully.
- **Env vars in Convex**: set via `npx convex env`. `JWT_PRIVATE_KEY` + `JWKS` are auto-generated by `npx convex dev` but can be pre-set. `LEMON_SQUEEZY_WEBHOOK_SECRET=272006`.
- **`.env.local`** is gitignored (matches `*.local` in `.gitignore`).
- **`window.location.href` used for checkout redirect** (popup blocker fallback).
- **No test suite** configured in package.json.
- **Driver GPS** shared every 5s via browser Geolocation API, stored in `driverLocations`.
- **Inline `<style>` tags** are banned — all CSS lives in `.css` files.
